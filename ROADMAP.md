# ORVEX — Product roadmap

This roadmap describes intended work, not completed features. Priorities may change after validation.

## Phase 0 — Foundation
- [x] Confirm ORVEX name and independent premium positioning.
- [x] Confirm French/English official communication.
- [x] Decide separate frontend/backend hosting.
- [x] Establish application scaffold and engineering conventions.
- [ ] Configure independent Netlify and Render deployments.
- [ ] Provision PostgreSQL and secure environment variables.
- [x] Add CI checks and basic automated tests (typecheck, production builds and runtime smoke tests).

## Phase 1 — Secure platform core
- [ ] Authentication, email verification and password reset.
- [ ] Organizations, workspaces, memberships and roles.
- [ ] Tenant isolation and server-side authorization.
- [ ] User profile, language preference and account settings.
- [ ] Admin foundation, audit events and operational health checks.

## Phase 2 — First business workflows
- [ ] Customer and prospect management.
- [ ] Products/services and sales records.
- [ ] Payment tracking and reminders.
- [ ] Dashboard and activity history.
- [ ] Export and basic reporting.

## Phase 3 — Learning and content
- [ ] Courses, lessons and learner access.
- [ ] Quizzes, certificates and events.
- [ ] Digital product delivery.
- [ ] Editorial assistant and guide studio.

## Phase 4 — AI and collaboration
- [ ] Provider-agnostic AI gateway with usage limits.
- [ ] Business audit assistant and knowledge base.
- [ ] Email/WhatsApp assistant (subject to provider and consent requirements).
- [ ] Private workspaces, demo builder and video workspace.

## Phase 5 — Monetization and scale
- [ ] Free, Starter, Pro, Business and Enterprise plans.
- [ ] Quotas, subscriptions, invoices and payment-provider integration.
- [ ] AI credit packs and marketplace options.
- [ ] Monitoring, backups, security review and load testing.

## Definition of done
A feature is not complete until its happy path, validation, authorization, failure states, tests, French/English copy and mobile layout have been checked.
